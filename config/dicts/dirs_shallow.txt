# 浅扫精选字典（dirscan.mode = quick 时**只用这一份**）
#
# 定位：用户要求"先浅浅过一遍"——只打**通用且偏敏感**的路径，单站请求量 ~150 条，
#       看清结果后再手动决定是否深度扫（深扫走 dirs_big / 框架桶 / dirmap，见 dirscan.mode）。
# 来源：① config/dicts/dirs_exposure.txt 的高价值条目；② 长期未被引用的 sensitive.txt；
#       ③ 公开资料里反复被提到的敏感文件/路径（VCS 泄露、环境文件、备份、中间件控制台、
#          框架管理端、信息泄露页）——人工筛选、去重、**按价值从高到低排序**。
# 顺序即优先级：`dirscan.quick_max_paths` 截断时靠前的先被扫到，所以不要把低价值条目插到前面。
# 维护：不联网下载（供应链与离网现场考虑）。要扩充请直接编辑本文件，
#       或用 tools/import_dir_dict.py 把外部字典清洗后导入。
