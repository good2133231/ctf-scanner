外部工具（版本管理）

这三个工具决定 subdomain / probe / 目录扫描三阶段的"上限"：没装时一律退到内置兜底 （cli --check 只会打印"未找到"），覆盖面与速度差一个量级。

本页是两个联网入口之一（另一个是 python cli/client.py --update-tools）： 只有点下面的按钮才会联网，扫描期任何阶段都不会自动下载。 下载只允许 https + 官方主机（{{ hosts|join(' / ') }}，含跳转后的真实地址）， 单产物上限 {{ max_mb }} MB，默认必须通过 release 自带的 SHA256 校验和（比对不过绝不落盘）； 解包只按预期文件名取（不用 extractall，并拒绝 .. / 绝对路径成员）。 安装目录：{{ dest }}/（当前平台 {{ platform }}）。
