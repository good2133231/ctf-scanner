外部工具（版本管理）

上表里被扫描路径调用的那些决定 subdomain / probe / 目录扫描三阶段的"上限"：没装时一律 退到内置兜底（cli --check 只会打印"未找到"），覆盖面与速度差一个量级。 afrog 是外部引擎（续149 起默认开）：vulnscan 会额外让它跑一轮组件识别 —— 但它只会被喂"只读 + info 级"的模板，且要同时满足"策略开关打开 + PoC 目录里有只读模板 + 本机装了 afrog"三条闸门才真的起进程，任何一条不满足都只写一行日志、零请求 （见 scanner/afrog.py）。另有 nmap / fscan / dirmap 需手工安装（见下方）， 本页不提供它们的下载入口。

本页是两个联网入口之一（另一个是 python cli/client.py --update-tools）： 只有点下面的按钮才会联网，扫描期任何阶段都不会自动下载。 下载只允许 https + 官方主机（{{ hosts|join(' / ') }}，含跳转后的真实地址）， 单产物上限 {{ max_mb }} MB，默认必须通过 release 自带的 SHA256 校验和（比对不过绝不落盘）； 解包只按预期文件名取（不用 extractall，并拒绝 .. / 绝对路径成员）。 安装目录：{{ dest }}/（当前平台 {{ platform }}）。

版本库（多版本共存）

通过本页装过的版本都会留在 {{ dest }}/{{ versions_dirname }}/<工具>/<版本>/， 可以在任意版本之间来回切（切换不联网）。旁边的「回滚」只能退一步（靠 .bak）， 这里能退到任意一个存过的版本；切换前会把当前这一份先归档，所以是可逆的。 每个工具最多留 {{ versions_keep }} 个版本，超出会按版本号从旧到新删掉（删了什么会在结果里说明）。
