# 门禁地图（档 A 局部验证 / 档 B 全量收尾）——唯一产地

> 主理人 2026-11-02 点单：「全量门禁是不是可以区域验证，每次修改跑全量有点浪费时间」。
> 答案是**分两档**，不是"少跑几组"：**开发中用档 A 拿秒级反馈，提交前那一次全量（档 B）一条不许省**。
>
> 为什么全量不能省——本会话（续303~续307）实测 7 次真红里 **6 次红在"我没改的那一组"**：
> `[8bq]` 被随包默认值翻档打红、GUI 路由被一个插错位置的 helper 抢走、浏览器 E2E 的第 10 节
> （默认勾选计数从 13 变 14）、`[219]②` 钉死了写死的模板名单、`[212]` 的 CLI 入口计数、`[218]` 的黑名单路径。
> 只跑"改动相关组"会全部漏掉。
>
> 机器形态在 `scanner/gateplan.py`（承重文件清单、档位算法、那句成语文案都只有一处）。
> **改这个文件必须同时改它**，`[308]` 会当场比对两边并判红。

## 档 A：开发中的局部验证（秒级 ~ 2 分钟）

```bash
./.venv/bin/python tests/smoke.py --only <组号,逗号分隔>     # 或 python dev.py smoke --only …
./.venv/bin/python tests/smoke.py --only <组号> --prefix    # 依赖前序夹具：从第一组顺序跑到该组
```

**依赖组的三个具体坑**（都真踩过）：

- 各组共享同一进程内的 `c = app.test_client()` 等状态，切片只跑后段会 `NameError` —— 把前置组一起点名。
- 手数前置组容易漏（`[5e]` 缺的是 `[3]` 建的 `tid`，不是相邻组）；`--prefix` 是第三条路：`--only 5e --prefix` 从 `[1]` 顺序跑到 `[5e]`，实测 **33.5 秒**（全量 613 秒），不改夹具、不重造数。**靠后的组别用**（`[310] --prefix` ≈ 全量，实现会打印「没有收益」）。
- `[308]` 读 `[8aa]` 的语料变量，单跑会直接 `SystemExit` 并告诉你 `--only 8aa,308`（**不是静默跳过**）。

## 档 B：提交前那一次全量（AGENTS §0.6，不许降档）

```bash
./.venv/bin/python tests/smoke.py            # 必须看到 SMOKE PASS
```

耗时实测（`--timing`，339 条组行、可归因 547.4s）：`[8aa] 129.3s`（占 23.6%）、`[7l] 35.8`、
`[7n] 32.4`、`[6u] 30.2`、`[8aq] 24.1`、浏览器 E2E 23.6、`[5e] 18.9`、`[170] 11.7`。

**只有"语料型"的那一块允许降档**，且降档是**算出来的**，不是人选的：

| 组 | 承重文件（碰到就跑全档） | 全档 | 降档 |
|---|---|---|---|
| `[8aa]` | `scanner/fingerprint.py`、`config/dicts/fingerprint_aliases.txt`、`config/dicts/fingerprint_fixes.txt`、`config/dicts/fingerprints_*.txt` | 2200 段随机语料 | 400 段（下限钉死 ≥200，防"降成空跑"） |

降档时**必须打印**那句说明（唯一产地 `gateplan.note()`）：

```
[gateplan] 本次降档 1 组：[8aa] 2200→400 段（改动没碰到承重文件…）｜其余全档
```

## 三条不许破的口径

1. **拿不到改动清单 ⇒ 一律全档**。`git diff` 失败、不在工作树、浅克隆没有 HEAD —— 都不许被读成
   "什么都没改"。CI 同理：`CI` 环境变量在 ⇒ 全档（CI 的 diff 天然是空的，拿它降档就是让流水线跑弱档）。
2. **不跳过任何一组**。降档只缩语料条数；判据本体（固定语料、覆盖率、计数对照、四个放弃条件、
   变异证伪）两档都跑。
3. **人工保险丝**：`CTFSCANNER_GATE_TIER=full` 强制全档（发版前、或你怀疑降档时用）。

## 收尾还有一句（与效率同等重要）

`tests/smoke.py --timing` 会把每组耗时写进 `logs/smoke-timing.jsonl`（每次跑覆写，默认关，
开启也不改变 stdout 内容）。要查"这轮慢在哪"就带它跑一次，别靠猜。
